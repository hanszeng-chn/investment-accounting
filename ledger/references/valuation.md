# 行情与净资产

quotes.py以标准库HTTPS拉取人民币场内证券腾讯日线未复权收盘价、场外基金天天基金单位净值。免费公开端点无长期稳定承诺；超时和一次重试后报告具体标的错误，保留旧价。不能执行下载JS，只解析所需数据。

```sh
python3 <skill>/scripts/quotes.py --root <data_dir> --as-of 2026-11-13
python3 <skill>/scripts/ledger.py --root <data_dir> dashboard --as-of 2026-11-13
```

默认上海当地当天。拒绝未来、非正、代码不符报价，保留provider/fetched_at/source_id和原始响应。市场SH/SZ必须显式，不能从地区主题猜。只抓已有标的。每持仓用截至日最近价格，份额日期与价格日期分别记录。默认超过7自然日显示过期，只是提醒阈值，不冒充交易日历。

腾讯日线可能包含当日盘中值；当日15点前的记录标为“当日日线最新价（未收盘）”，看板提示盘中价，不称为已收盘价格。

未确认现金或完整覆盖时只能称证券估值，账户汇总继续人工资产。自动结果从事件/行情派生，不修改人工估值。启用完整自动净资产需要account_updates将valuation_mode设holdings、holdings_complete设true，并补已知CASH_BALANCE。

本版不自动抓取所有分红拆分公告；确认到账金额/份额后手动记相应事件，存在未核对权益时说明。其他币种/市场使用来源明确的quote批次。未配置调度时只在调用更新，不声称后台定时；另行授权配置调度不隐含自动公开发布授权。
