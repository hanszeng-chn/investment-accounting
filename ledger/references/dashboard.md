# 静态看板规则 v2

HTML严格只读，不提供归档、恢复或其他写入入口，也不保留写入API、令牌或占位钩子。归档状态仅从账本读取。已归档账户只在页面最底部“已归档资产”details折叠区展示，默认收起，可展开查看历史盈利；不在主账户列表、当前持仓表或资产分布展示。资产分布同时不画零余额账户，分母只含未归档正余额资产。历史曲线、累计损益和完整流水保留，汇总卡说明含归档账户。不要替用户自动选择要归档的账户。

收益面板遵循[收益口径](returns.md)，提供账户/区间选择和年度明细，维护scripts/performance.py而非在HTML拼凑金融计算。

人民币单币种页面不显示币种选择器、CNY标题后缀；内部仍保留币种字段，未来多币种须分开显示，不按1:1混合。

静态文件可独立打开和部署。可运行 `python3 <skill>/scripts/serve_dashboard.py --root <data_dir> --port 8765` 在本机预览。服务仅提供已生成HTML的读取，拒绝POST/PUT/PATCH/DELETE，不生成写入令牌、不在访问时修改账本或生成页面。数据更新和归档由skill通过账本命令完成，再显式重新生成HTML。

生成器scripts/ledger.py dashboard，模板assets/dashboard.html。单文件HTML内联CSS/JS/SVG，无CDN/追踪/后端，可本地打开和静态托管。桌面及390px手机可读，表格横向滚动。

本地页含分币种资产/投入/损益、估值日期、资产与投入曲线、账户、持仓、操作和待补充。曲线只在有记录日期计算并标记前值延续。未知不填虚构0；混合日期明确提示。不虚构年化或基准。

账户概览展示七列：账户、当前资产、净投入、累计收益、资金加权收益率、年化收益率、估值日期。新增收益率固定使用该账户记账以来的Modified Dietz和365天年化结果，不随上方收益面板的区间切换改变；缺失时显示暂无或待核对，不冒充0%。不展示重复的持仓估值、额外行情日期、估值方式或状态。账户和归档区均无写入按钮。标的价格和行情日期保留在持仓明细，人工总资产及其更正保留在投资记录，相关字段仍保存在数据中。

```sh
python3 <skill>/scripts/ledger.py --root <data_dir> dashboard
python3 <skill>/scripts/ledger.py --root <data_dir> dashboard --public
python3 <skill>/scripts/ledger.py --root <data_dir> dashboard --public --disclose amounts
python3 <skill>/scripts/ledger.py --root <data_dir> dashboard --public --disclose full
```

本地完整版写dashboard/index.html。
分享版写public/index.html：默认redacted仅含分币种比例、首个非零资产为100的指数曲线、数据日期和数量；从文件移除金额、份额、真实账户/标的名、代码、流水、来源路径和备注，隐藏按钮不算移除。
amounts只公开分币种总额/损益和汇总曲线，不含账户/标的/流水。full公开完整金融视图但不含来源原件和技术ID，仅在用户明确选择公开明细时用。

“可能部署”只生成可部署文件。用户明确要求发布时用现有托管工具/账号，核实现行免费额度，说明这次文件含什么，且仅上传public目录，不能发布整个账本目录。静态HTML内容所有访问者可读取，前端隐藏/密码不提供可靠访问控制。deployment.json记录提供方、URL、披露模式和更新时间，不含token；后续只按已授权范围发布。

持续迭代修改模板与此规则，保持数据接口兼容。检查金额、零/缺失、代码前导零、HTML转义、无外部请求、移动与桌面布局。计算口径变化需升级schema并迁移，不能悄改历史。

v2支持投入核对快照：对账日前历史曲线沿用当时明细，对账日起净投入按已核对汇总及其后资金流计算，并显示差额待核对提示。投入核对与真实资金进出用不同记录类型，不影响证券估值或现金。简单损益率不能冒充截图中算法未知的收益率。

## 看板规则 v3（2026-11-16）

顶部四卡为资产估值、累计损益、记账以来年化收益率、本月资金加权收益率；不放净投入卡。移除独立“资产与净投入”曲线。账户资产分布增加权益占比示意，按A股资产、港股、美股账户汇总，分母为未归档正余额资产；REITs、黄金、债券与现金不计入权益，页面明确此账户级分类口径。

投资收益不再展示收益/资金加权/年化指标卡，保留年度明细表。增加账户、区间与收益金额/资金加权收益率切换的曲线。点数据在performance.py中生成，沿用相同起止事件边界和资金流筛选，资金转入不能算盈利；记账以来收益金额采用各日已核对累计收益。只连接已有记录，不伪造每日历史行情。曲线与收益表终点一致，缺少可靠端点或未定位现金流差额时不画误导性区间曲线。

AES解锁后直接在当前文档渲染完整HTML，不使用Blob iframe（兼容移动WebKit/微信内置浏览器），不提供“锁定看板”按钮。刷新重新进入密码页；使用Web Crypto解密，不依赖外部脚本。移动与桌面验证应覆盖解锁后的真实页面及交互，不能只验证密文能解开。

## 暖白组件版（2026-11-16）

视觉采用已选定的03号个人资产风格：暖白、灰绿、舒展排版。源码位于项目`dashboard-ui/`，复用shadcn Card/Table/Button，曲线与分布使用Recharts；运行`node scripts/build-dashboard-ui.mjs`编译生成本模板，禁止直接修改编译后的`assets/dashboard.html`。最终仍为独立HTML，内联全部CSS/JS，无CDN和iframe；Python数据生成接口与收益算法保持不变。

曲线触屏长按350ms查看最近有效记录点，按住左右拖动；普通滑动取消待触发长按并保留页面滚动。松手保留最后选点，支持清除；桌面悬停及键盘左右/Home/End/Escape可查看。显示实际记录日期、金额/收益率及最近已知估值提示，缺失值不补零、null保持断点、不平滑或伪造日线。切换账户、区间或指标清除旧选点。金额隐藏只是本机显示功能，不代替分享版数据裁剪或AES加密。

侧边栏按当前阅读位置更新高亮和aria-current，支持普通滚动、锚点跳转与布局变化。整站使用放大后的可读字号，手机表格局部横向滚动。

源码构建同时生成只含runtime代码的内容哈希ZIP包与模板。发布时将LEDGER_RUNTIME_KEY设为构建输出的runtime_key；部署后通过本人investment_open_session动作把包安装到R2，并按当前dashboard_key和revision比较交换刷新看板指针，不更改账本内容、账本版本或记账时间。普通页面GET不写数据。若期间有新账本提交，重新读取最新看板后再换肤，不覆盖新交易。Netlify仍只上传AES加密文件，沿用已授权的密码。
