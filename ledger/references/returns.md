# 收益面板与口径

计算脚本scripts/performance.py；参考本项目mobile/src/domain/returns.ts、mobile/src/ui/reporting.ts及其边界测试。金额用Decimal，收益率显示两位小数。

- 资金加权：Modified Dietz近似，分子=期末资产-期初资产-区间净流入；分母=期初资产+按剩余天数加权的资金流。起始日流权重1、结束日0。不是XIRR。
- 年化：(1+区间收益率)^(365/实际天数)-1。仅同日、不正加权基数、收益率不大于-100%或数值溢出时不可计算。不足一年注明为折算，不能称预期收益。
- 时间加权：按实际估值子区间连乘，每段剔除该日净流入；资金流日、起点或终点缺实际估值时显示原因，不能拿前值延续冒充当天估值。
- 区间取该月/年内实际首末估值，显示日期，不凭空补1月1日。资金流按date/order严格裁至起止估值边界，终点之后的同日转出不能倒算成收益。
- 组合计算按同币种所有账户，包含归档历史；新增账户的正期初余额计作该时点纳入组合的资金。内部转账在组合中抵消，不算新投入；单账户保留分类资金进出。
- A股等存在投入核对快照且历史差额未定位时，受影响历史收益率显示待核对，不把累计差额塞进某天流量来计算MWR。核对日后的独立区间可以计算。
- 组合端点若含异步估值须明确参考口径；时间加权只用完整实际估值。清零且无重新投入的账户，停止在实际清零估值日，不因后续完整性确认延长年化时间。

面板可选择全部资产/各账户以及本月、今年、记账以来；包含区间收益、资金加权、对应年化、时间加权四卡及年度表。主汇总第四卡改为本月MWR，不再突出简单损益率。分享的脱敏/汇总版不嵌入账户级收益明细。

默认显示记账以来。累计收益金额取当前资产减已核对净投入，即使历史资金流时点未齐也应展示；不能因为收益率不可计算而清空已知收益金额。涉及未定位差额的收益率标为待核对并说明原因，数据齐全的其他账户继续显示正常结果。

时间加权收益率无可用数值时隐藏卡片及对应缺失说明；年度表整列均无值时隐藏该列。某些年度有值则保留列，缺失单元格留空，不用暂无占位。全部时间加权值缺失时也隐藏其方法说明；数值0是有效结果，不能当缺失隐藏。保留后台计算数据，以便后续估值齐全后自动显示。

找到真实缺失流水后，撤销被其替代的临时BASIS_CHECKPOINT并解决对应pending，恢复按实际业务日期计算资金加权。若原表总资产与投资日志存在加法矛盾，另建affects_valuation类型pending：仅当该日作为MWR起止端点时阻断该区间MWR；作为中间估值不影响MWR的起末资产与真实流量，不能因此继续屏蔽记账以来MWR。TWR包含该可疑估值时应待核对。
